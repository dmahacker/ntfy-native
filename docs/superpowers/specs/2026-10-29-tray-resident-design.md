# 托盘常驻与未读提醒

## 已批准的行为

- 未配置时启动显示配置窗口；已有配置时启动不显示窗口，Rust 后端自动恢复订阅。
- 关闭窗口改为隐藏，继续收消息；托盘菜单「退出」才结束程序。
- 菜单提供查看消息、连接设置、连接／断开、退出。窗口区分消息视图与配置视图，平时不展示配置表单。
- 以 SVG 为源制作简洁的铃铛图标，并生成平台所需位图。未读显示圆点；断线具有不同标记。
- 打开消息列表清除未读；仅当消息视图可见且窗口处于前台时，新消息直接视为已读。系统通知照常发送。
- 托盘创建失败时显示窗口并说明原因，关闭窗口正常退出，不能留下无入口的后台进程。

## 实现约束与默认选择

沿用现有 Tauri 2 / React、单服务器单主题和本地明文配置。已有去重和重连规则不变，不新增开机启动、消息落盘、多主题或通知按钮。未读状态仅在本次进程运行期间保存；未读标记独立于最多 100 条消息列表。

Rust 是订阅和未读状态的唯一来源，前端挂载不得重新订阅、清空消息或改变未读状态。启动先隐藏窗口，后端读取配置并决定是否显示，避免闪现。配置损坏时显示配置页及脱敏错误；认证或网络故障只改变托盘状态，不抢焦点。

图标采用四种组合：正常、未读、离线、离线且未读；无未读时离线标记不被误解为新消息。托盘文字显示连接状态和未读数，但不依赖悬浮提示实现核心交互。Linux 通过菜单提供所有入口，不依赖各桌面支持情况不同的左键事件。

首次保存并连接成功后隐藏配置窗口进入托盘；清除配置后保留配置页。托盘不可用时保存后不隐藏。关闭消息窗口不重置消息或连接；从托盘重新连接沿用现有手动连接语义。托盘退出显式结束进程。

SVG 源文件与生成位图均提交，运行时不解析 SVG。应用图标替换默认 Tauri 图标。Windows / macOS / Linux 的实际托盘、通知展示仍需在对应桌面验收；无图形环境不得声称已实测。
